# Remaining master-scope extensions

The core consumer MVP is implemented on this branch. The following items are intentionally tracked as next-stage extensions rather than silently claimed as complete:

- Persisted AI-generated meal library beyond the seeded recipe set
- Nutrition/macros scoring when reliable product nutrition data is available
- Multi-user authentication / accounts
- Background/scheduled REWE refresh jobs
- Additional supermarkets beyond REWE
- Real checkout/cart write integration (not implemented by design)
- Push/email notifications
- Production deployment hardening (managed DB, secrets, observability)
- Advanced drag-and-drop meal calendar
- Historical analytics dashboard

These are not required for the current local single-user MVP loop to function.
